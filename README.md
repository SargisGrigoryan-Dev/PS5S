# PS5S: Experimental PS5 Emulator

A PlayStation 5 emulator for Windows, built from scratch by reverse engineering.
It runs open-source PS5 homebrew (LakeSnes, Wolf4SDL, OpenJazz) with picture,
sound and controller input.

**Website:** https://sargisgrigoryan-dev.github.io/PS5S/

This repository contains the project page only (screenshots and logs).
Source code is not published yet.

PS5S contains no Sony code, keys or firmware and does not decrypt anything.
It is not affiliated with Sony Interactive Entertainment.
